# Live Research & Tech Intelligence Skill

This skill equips the agent with continuous awareness of breaking developments, technological breakthroughs, security advisories, and market shifts.

## Core Capabilities

1. **Real-Time Intelligence Feeds (`fetch_latest_intelligence`)**:
   - `ai_tech`: Breakthroughs in reasoning models, agent frameworks, open-source weights, and multimodal APIs.
   - `cybersecurity`: Zero-day disclosures, CVE bulletins, OSINT attack vectors, and credential leak mitigation.
   - `freelance_trends`: High-demand tech skills, surging API integration requests, and hourly rate benchmarks.
   - `hardware_gaming`: GPU architectures, neural shaders, performance metrics, and memory bandwidth advances.

2. **Structured Deep Research Dossiers (`deep_research_dossier`)**:
   - Transforms any topic into a 5-pillar intelligence report:
     - Core Thesis
     - Technical Mechanism
     - Breaking Developments
     - Security & Risk Audit
     - Strategic Action Plan

## Research Best Practices
- Never rely on single-source hearsay; require primary documentation, GitHub commits, or benchmark whitepapers.
- Distinguish verified benchmark data from marketing hype.
- Translate theoretical discoveries directly into usable code tools and workflows.
