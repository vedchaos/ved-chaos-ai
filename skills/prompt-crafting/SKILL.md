# Professional Prompt Engineering Skill (Ved-Style Expert Edition)

This skill equips an agent with battle-tested frameworks to turn simple, vague instructions into high-precision, production-grade, professional prompts.

## Core Pillars of a Brilliant Prompt

Every professional prompt must contain five non-negotiable structural elements:
1. **Role & Authority Framing**: Establishes expert perspective (e.g., "Principal Software Architect", "Cinematographer & AI Art Director").
2. **Context & Problem Scope**: Defines precise boundaries, domain state, and operational environment.
3. **Actionable Directives & Step-by-Step Reasoning**: Enforces clear methodology, chain-of-thought analysis (`<thinking>`), and deterministic logic.
4. **Negative Constraints**: Explicitly forbids common failure modes, placeholders, hand-waving, hallucinations, or conversational filler.
5. **Deterministic Output Schema**: Declares exact expected output structure (JSON schema, markdown sections, or code blocks).

## Domain Archetypes

### 1. Coding & Software Architecture
- **Directive**: Enforce type hints, defensive error handling, boundary checks, zero placeholders, and automated unit tests.
- **Key Constraints**:
  - Never emit `// rest of implementation here` or truncated code.
  - Separate business logic from I/O and configuration.
  - Include algorithmic complexity (Time & Space $O(n)$) when relevant.

### 2. AI Art & Visual Concept Design (Midjourney / Flux / SD)
- **Directive**: Cinematic composition, volumetric lighting, specific focal length, and render engines.
- **Key Elements**:
  - Subject + Pose + Environment.
  - Lighting: Volumetric fog, rim lighting, bioluminescence, golden hour, moody chiaroscuro.
  - Camera & Optics: 85mm f/1.4 lens, wide-angle cinematic, sharp focus, hyper-realistic micro-textures.
  - Render Engine: Unreal Engine 5, Octane render, 8k resolution, trending on ArtStation.
  - Strict Negative Prompt: Mutated hands, extra limbs, blur, watermarks, oversaturated artifacts.

### 3. LLM System Prompts & Personas
- **Directive**: Jailbreak resistance, persona consistency, strict refusal conditions, and chain-of-thought scratchpad.
- **Key Elements**:
  - Identity definition with behavioral bounds.
  - Input parsing -> Constraint verification -> Output generation workflow.

### 4. Workflow Automation & API Integrations
- **Directive**: Idempotency, rate limit compliance, exponential backoff, webhook verification, structured telemetry.

### 5. OSINT & Cyber Reconnaissance
- **Directive**: Advanced Google dorking syntax (`site:`, `inurl:`, `filetype:`), source triangulation, passive footprint minimization.
