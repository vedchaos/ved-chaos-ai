# Ved Chaos Codebase Intelligence & Self-Upgrade Skill

Provides Ved Chaos AI with full-stack codebase ingestion, dependency CVE auditing, persistent structured reasoning, offline-first FTS5 memory, and live GitHub repository scouting.

## Branded Ved Chaos AI Tools
1. **`ved_ingest_codebase`**: Packs any local directory or public GitHub repo (`owner/repo`) into clean Markdown or XML with ASCII tree, token estimation, `.gitignore` filtering, and automatic secret redaction.
2. **`ved_scan_supply_chain`**: Parses `requirements.txt`, `pyproject.toml`, and `package.json`, queries OSV.dev for known CVEs, and runs Shannon entropy + regex secret detection across project files.
3. **`ved_manage_reasoning_chain`**: Persistently logs, revises, branches, and concludes multi-step reasoning chains inside `state.db`.
4. **`ved_scout_github_upgrades`**: Searches GitHub for high-signal repositories and evaluates permissive license compatibility (`MIT`, `Apache-2.0`, `BSD`) for future Ved Chaos AI upgrades.
5. **`ved_get_capabilities_manifest`**: Reports Ved Chaos AI's active version, memory backend, and upgraded module inventory.
